# 06 — 视觉风格指南

> 基于 **Linear** 设计语言，结合 PrimeVue Aura 主题，适配 WeClawBotNotify 管理后台。
> 风格一句话：**深色优先、极简精确、紫色点缀、数据驱动**。

---

## 一、设计原则

| 原则 | 说明 | 来源 |
|------|------|------|
| **内容即界面** | 去掉装饰元素，让数据表格本身成为视觉重心 | Linear ultra-minimal |
| **减少层级** | 能用一行文字说清的不用卡片包裹，能内联编辑的不弹窗 | Linear precise |
| **操作可达** | 高频操作（创建、删除）不超过 2 次点击 | 本项目交互需求 |
| **深色优先** | 默认暗色主题，亮色为可选。通知/监控类产品长时间注视，暗色减少视疲劳 | Linear dark-first |
| **状态可辨** | 每个实体的状态通过「小色点 + 简短文字」一眼识别 | Linear status indicators |

---

## 二、配色方案

### 2.1 主色系 — 靛蓝紫

Linear 使用偏蓝的紫色作为品牌色，传递「精准、专业」的感觉。PrimeVue Aura 的默认 primary 可通过 design token 覆盖。

| 色阶 | HEX | 用途 |
|------|-----|------|
| `primary-50` | `#EEF0FF` | 极浅背景（选中行） |
| `primary-100` | `#D9DDFF` | 浅色背景 |
| `primary-200` | `#B3BAFF` | — |
| `primary-300` | `#8C96FF` | — |
| `primary-400` | `#6673FF` | 禁用态文字 |
| `primary-500` | `#5E6AD2` | **主色基准** — 主按钮背景、链接、选中态 |
| `primary-600` | `#4B55B8` | 主按钮 hover |
| `primary-700` | `#3A429E` | 主按钮 active |
| `primary-800` | `#2A3084` | — |
| `primary-900` | `#1C206A` | — |
| `primary-950` | `#101450` | — |

### 2.2 语义色

| 语义 | 色值 | 用途 |
|------|------|------|
| **Success** | `#34D399` (emerald-400) | Client 已绑定、操作成功 |
| **Warning** | `#FBBF24` (amber-400) | Client 等待扫码、待处理 |
| **Danger** | `#F87171` (red-400) | 删除按钮、Client 错误、Token 过期 |
| **Info** | `#60A5FA` (blue-400) | 消息通知提示 |

### 2.3 中性色（暗色主题）

| 层级 | Tailwind Class | 用途 |
|------|---------------|------|
| **Page Background** | `bg-surface-950` | 页面最底层背景，最深色 |
| **Sidebar** | `bg-surface-900` | 侧边栏背景，略浅于页面 |
| **Card / Table** | `bg-surface-800` | 卡片、表格容器 |
| **Input / Dialog** | `bg-surface-700` | 输入框、弹窗背景 |
| **Hover** | `bg-surface-600` | 表格行悬停、菜单项悬停 |
| **Border** | `border-surface-500` | 分割线、表格边框 |
| **Muted Text** | `text-muted-color` | 次要文字、时间戳、描述 |
| **Body Text** | `text-color` | 正文、表格内容 |
| **Emphasis Text** | `text-color-emphasis` | 标题、强调文字 |

### 2.4 中性色（亮色主题 — 可选）

| 层级 | 用途 |
|------|------|
| `bg-white` | 页面背景 |
| `bg-surface-50` | 侧边栏 |
| `bg-surface-100` | 表格头部 |
| `bg-white` | 表格行 |
| `bg-surface-50` | 表格行悬停 |
| `border-surface-200` | 边框 |

> 以上颜色均通过 `tailwindcss-primeui` 插件的语义 class 使用，不需要手写 HEX 值。

## 三、字体排印

### 3.1 字体家族

| 用途 | 字体 | 备选 |
|------|------|------|
| 英文/数字 | **Inter** | system-ui, -apple-system |
| 中文 | PingFang SC | Microsoft YaHei |
| 等宽（Token/代码） | JetBrains Mono | SF Mono, Consolas |

### 3.2 字号层级

| 层级 | 大小 | 字重 | 用途 |
|------|------|------|------|
| **Page Title** | 20px | 600 (Semibold) | 页面大标题「Dashboard」 |
| **Section Title** | 16px | 600 | 区块标题 |
| **Table Header** | 13px | 500 (Medium) | 表格列头 |
| **Body** | 14px | 400 (Regular) | 表格内容、表单文字 |
| **Caption** | 12px | 400 | 时间戳、描述文字、辅助信息 |
| **Token / Code** | 13px | 400 (等宽) | Application Token 展示 |

### 3.3 排版规则

- 行高：正文 1.5，标题 1.3
- 段落间距：正文段落间 12px
- 标题与内容间距：标题下方 8px
- **Linear 风格特征：负字间距** — 大标题使用 `tracking-tight`（`letter-spacing: -0.025em`），让文字更紧凑有力

## 四、间距系统

采用 **4px 基准** 的 8 点网格系统（Tailwind 默认）。

| Token | 值 | 用途 |
|-------|-----|------|
| `gap-1` | 4px | 图标与文字间距、Tag 内边距 |
| `gap-2` | 8px | 表单字段间距、按钮组间距 |
| `gap-3` | 12px | 卡片内元素间距 |
| `gap-4` | 16px | 区块间距、表格与分页间距 |
| `gap-6` | 24px | 段落间距、弹窗内容间距 |
| `gap-8` | 32px | 页面内容区上下边距 |
| `p-4` | 16px | 卡片/弹窗内边距 |
| `p-6` | 24px | 页面内容区左右边距 |

### 页面级布局约束

| 元素 | 尺寸 | 说明 |
|------|------|------|
| 侧边栏宽度 | 220px（展开）/ 60px（折叠） | 展开时显示图标 + 文字，折叠时仅图标 |
| 内容区最大宽度 | 1200px | 内容区居中，超过此宽度两侧留白 |
| 表格最小宽度 | 页面宽度 - 48px | 表格撑满内容区 |

## 五、页面模式

### 5.1 列表页（Client / Application / Message）

这是本项目**最高频的页面类型**，Linear 风格在此发挥最大价值。

```
┌─ 页面 ─────────────────────────────────────────────┐
│                                                     │
│  ┌─ 头部 ───────────────────────────────────────┐  │
│  │  Page Title (20px)              [+ 创建] 按钮 │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
│  ┌─ 表格 ───────────────────────────────────────┐  │
│  │  Header (13px, uppercase, muted)              │  │
│  │  ─────────────────────────────────────────── │  │
│  │  Row (14px)                                   │  │
│  │  Row (14px)  ← hover: bg-surface-600          │  │
│  │  Row (14px)                                   │  │
│  │  ...                                          │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
│  ┌─ 分页 ───────────────────────────────────────┐  │
│  │  共 N 条           ◀ 1 2 3 ▶                  │  │
│  └──────────────────────────────────────────────┘  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**表格规范：**

| 规则 | 值 |
|------|-----|
| 行高 | 40px |
| 列头高度 | 36px |
| 列头文字颜色 | `text-muted-color` |
| 列头文字大小 | 13px, Medium |
| 行悬停背景 | `bg-surface-600`（暗色） |
| 边框 | 无竖线，仅底部横线 `border-surface-500` |
| 行选择 | 复选框在最左侧列 |
| 操作列 | 固定在右侧，文字按钮（非图标），Danger 操作用红色 |

**状态 Tag 规范（Linear 风格小色点）：**

```vue
<!-- Client 状态 -->
<Tag severity="success" value="bound" />     <!-- 绿 -->
<Tag severity="warn" value="pending" />      <!-- 黄，等待扫码 -->
<Tag severity="danger" value="error" />      <!-- 红 -->

<!-- Message 优先级 -->
<Tag severity="danger" value="high" />       <!-- 高优先级: 红 -->
<Tag severity="warn" value="medium" />       <!-- 中优先级: 黄 -->
<Tag severity="info" value="low" />          <!-- 低优先级: 蓝 -->
```

**表单规范：**

### 5.3 弹窗页（创建 Client / 创建 Application）

**Linear 风格弹窗的关键特征：小而聚焦。**

```
┌─ 遮罩层 (bg-black/50) ───────────────────┐
│                                            │
│   ┌─ Dialog ──────────────────────┐       │
│   │  Title (16px, semibold)       ✕ │       │
│   │  ───────────────────────────── │       │
│   │                                │       │
│   │  Form Fields                   │       │
│   │                                │       │
│   │  ───────────────────────────── │       │
│   │           [取消]  [创建]       │       │
│   └────────────────────────────────┘       │
│                                            │
└────────────────────────────────────────────┘
```

**弹窗规范：**

| 规则 | 值 |
|------|-----|
| 弹窗宽度 | 440px（除非内容需要更宽） |
| 弹窗圆角 | 12px |
| 遮罩层 | `bg-black/50` |
| 入场动画 | 淡入 + 轻微上移（PrimeVue Dialog 默认） |
| 标题与内容分割线 | 无，靠间距分隔（Linear 极简特征） |
| 底部按钮 | 右对齐，取消在左、主操作在右 |

### 5.4 Token 一次性展示（创建 Application 后）

```
┌─ Dialog ───────────────────────────┐
│  ⚠️ Application 创建成功           │
│                                    │
│  Token 仅显示一次，                 │
│  请立即复制并妥善保存               │
│                                    │
│  ┌─ Token ───────────────────┐    │
│  │ app_a1b2c3d4...      [📋] │    │
│  └───────────────────────────┘    │
│                                    │
│             [我已保存，关闭]        │
└────────────────────────────────────┘
```

**关键安全原则：**
- Token 仅存在组件 `ref` 中，关闭即销毁
- 不写入 Pinia、localStorage、sessionStorage
- 提供一键复制按钮（`useClipboard` from VueUse）

## 七、微交互规范

### 7.1 按钮

| 状态 | 表现 |
|------|------|
| Default | 背景 `primary-500`，文字白色 |
| Hover | 背景 `primary-600`，轻微上浮（`translateY(-1px)`） |
| Active | 背景 `primary-700`，回落原位 |
| Disabled | 灰色背景，`cursor: not-allowed` |

### 7.2 表格行

| 状态 | 表现 |
|------|------|
| Default | 背景透明 |
| Hover | 背景 `bg-surface-600`，过渡 150ms |
| Selected | 背景 `bg-primary/10` |

### 7.3 输入框

| 状态 | 表现 |
|------|------|
| Default | `border-surface-500` |
| Focus | `border-primary-500`，外发光 `ring-2 ring-primary/20` |
| Error | `border-danger`，外发光 `ring-2 ring-danger/20` |

### 7.4 过渡动画

| 场景 | 时长 | 缓动 |
|------|------|------|
| 弹窗打开/关闭 | 200ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| 表格行 hover | 150ms | `ease-out` |
| 侧边栏折叠 | 200ms | `cubic-bezier(0.16, 1, 0.3, 1)` |
| Toast 消息 | 300ms | `ease-out` |

## 八、响应式策略

### 8.1 断点

| 断点 | 宽度 | 布局变化 |
|------|------|----------|
| Mobile | < 768px | 侧边栏隐藏（汉堡菜单），表格水平滚动 |
| Tablet | 768px – 1024px | 侧边栏折叠态，表格撑满 |
| Desktop | > 1024px | 完整布局 |

### 8.2 适配规则

- 侧边栏在 < 768px 时变为浮层（overlay），点击遮罩关闭
- 表格在窄屏时开启水平滚动，**不隐藏列**（管理后台的操作列不能隐藏）
- 弹窗在 < 440px 时宽度变为 `100vw - 32px`
- 表单页在移动端取消居中卡片，直接全宽显示

## 九、空状态 / 加载态 / 错误态

### 9.1 空状态（列表为空时）

```
┌─ 内容区中央 ─────────────────────┐
│                                    │
│           [空状态图标]              │
│        暂无 Application            │
│    创建第一个推送凭证开始使用        │
│                                    │
│          [创建 Application]         │
│                                    │
└────────────────────────────────────┘
```

- 图标使用 PrimeIcons 或自定义 SVG，颜色 `text-muted-color`
- 标题 16px semibold，描述 14px muted
- 主操作按钮直接放在空状态中（Linear 风格：减少用户寻找按钮的步骤）

### 9.2 加载态（数据请求中）

- 表格区域显示 **Skeleton** 骨架屏（PrimeVue DataTable `loading` + `Skeleton`）
- 骨架屏行数为表格每页行数（如 20 行）
- 首次加载用骨架屏，刷新操作用 DataTable 内置的 `loading` mask

### 9.3 错误态（请求失败）

- Toast 消息提示错误信息
- 表格区域显示「加载失败，点击重试」+ 重试按钮
- 不刷新整个页面
